# 新华街楼群：绘制结论

楼群的平面、朝向和高度类别分别表达；下列为概括体量，单栋身份、精确层数与建成年仍按数据中的不确定性处理。

| 楼群 | 可用体量关系 |
| --- | --- |
| 三里 | 临街三栋塔楼；后排两栋塔楼与五栋板楼；保留庭院和间隔 |
| 五里西 | 塔楼与六层板楼混合 |
| 五里东 | 长条及折线体量，高度不一，不统一画成六层板楼 |
| 七里 | 塔楼与独立长条电梯楼分开；西向门脸面向四环 |
| 四里 | 四个主要长条住宅体量；与六里分开 |
| 六里 | 七个主要住宅体量，围栏和院门独立 |
| 南开西里 | 板楼及内部巷道；总栋数和完整边界未确定 |

南侧保留八里、六里、四里、二里、供暖设施及东侧学校的相对关系。东侧背景学校不替代两个待定位历史学校。独立临街低房与住宅主体分开，底商不自动意味着结构相连。

近景取舍由 [轮廓流程](XINHUA_OUTLINE_WORKFLOW.md)管理；当前正式总览使用 [空间绘制契约](XINHUA_SPATIAL_PIPELINE.md)。现代几何不认证历史建成年，视觉认可不认证单栋层数。
