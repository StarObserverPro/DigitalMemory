# 丰台镇桥区与正阳大街：公共史料与时空节点

> **2026-10-26 integration:** Public historical research imported from a prior review branch. No private oral recollection, personal route, registered bridge geometry, scene assets or public memory entries were added.

> **性质**：公共历史考证索引；非个人回忆、非获批地图文案。  
> **研究日期**：2026-10-19。**状态**：文献核对完成第一轮；旧桥拆除年、空间轮廓及部分桥名仍待补证。  
> **适用范围**：丰台镇桥南／桥北的公共地理背景；不改变 [Phase 1](../PHASE_1.md) 的新华街优先范围，不自动扩充建设范围。  
> **界限**：不包含原始口述、个人居住迁移、私人行走路线、私有相片或个人视角便签。未经审核的记忆不得因本索引进入公有运行内容。

## 1. 核心地理关系

铁路对丰台镇的长期分隔，产生**桥北**（老丰台站北侧的正阳大街、早期商业与行政设施）和**桥南**（铁路机务／车辆等单位、职工生活区）的生活地理区分。旧丰台站1895年始建，老站向北开口，正阳大街在铁路北侧形成商业中心。车站与商业街是城镇公共组织的重心，**不等于任何特定人的生活或记忆中心**。

正阳大街为官方写法（`正阳`，不是`郑阳`）。2012年的地方回忆资料说全街约1.3 km；2025年报道的三维重建只覆盖重点**748 m**，两者不是同一范围的长度数据。

这些事实支持两条彼此独立的检索路径：
1. **城市历史**：铁路枢纽 → 车站北出入口 → 正阳大街商业街 → 桥梁更新。
2. **空间导航**：城市概览 → 桥区或街段 → 不同时代的独立桥实体与附近公共地标。

不得根据一段通用地方历史来虚构某位用户穿行、停留或消费过的节点。

### 旧桥的结构沿革与证据冲突

- **1907年**：北京旅游网《百年丰台站》记载在平交道口建木桥。
- **1930年代**：同文记载七七事变前日军将木桥改为约55 m长、10 m宽的水泥墩钢架桥。1993年《北京市丰台区地名志》（由《丰台时报》2025年转引）以“始建于40年代”描述旧桥，可能指不同阶段结构，尚不能把两个“始建”统一为一座桥的建造年。
- **1968年**：北京旅游网称加高为约5.8 m净高、钢筋混凝土桥；陡拱使步行／骑行跨铁路艰难。地方回忆还记载北引桥向西弯折以缓坡，不同时代的引桥可能发生变化。
- **1988—1990年**：新公路桥与铁路下穿四环工程施工、开通。北京旅游网另称1988年北引桥被切断，1990年底老桥走到终点。
- **1990年前后旧桥是否仍存，拆除具体哪年？** 2025年《丰台时报》援引**1993年12月出版**的《北京市丰台区地名志》，其中写“旧桥和新桥两部分组成”“旧桥仅作行人和非机动车使用”。但该志公开书目所载的**资料内容下限是1990年**，所以它并不能证明旧桥在1993年仍然存在。北京旅游网把1990年底作为老桥终点，和地名志所描述的1990年前后并存状态不一定矛盾；**旧桥主体具体拆除日期仍未知**。需查施工竣工档案、早期航拍，不能把1993出版年作为现场有效年份。

### 桥名检索与用户界面

`丰台大桥` 不能视作全球唯一的物体正式主键。历史资料既以它指旧跨铁路桥，又用于1988—1990新公路+铁路成组工程；如今社会/工程文本还同时出现“正阳桥”“北京丰台特大桥”。可采用：

```text
BridgeIdentity          object ID / distinct geometry / validity interval
PlaceAlias              "丰台大桥" / "旧丰台大桥" / "正阳桥" / "罗锅桥" ... + period/source
BridgeComplexRelation   partOf / nextTo / replaces / overpasses / same-corridor-not-same-structure
```

对尚未确认的口头别称只建立 `alias-candidate`，不因同名合并实体。新旧桥毗邻、可能**同时存在**，时间层不能用“后桥覆盖前桥”代替真实的并存关系。

## 3. 正阳大街：商业沿革的公开时间轴

| 阶段 | 来源支持的叙述 | 注意边界 |
| --- | --- | --- |
| 1895年以后 | 老站成形，铁路客货运输推动站前旅店、货栈、商铺发展；正阳大街成为重要商业街。 | 不推断每家店的具体始末年份。 |
| 20世纪50—80年代 | 国营／集体性质及各类零售服务业集聚，前站街北侧大量店面：新华书店、丰台百货公司／商场、丰春楼、丰泉浴池、照相馆、邮电局、食品与药店等。 | 店铺清单主要来自2012年街坊亲历的回忆文章；仍须从旧照片及档案定位。 |
| 1988—90年代 | 四环改建及城市商业体系转换，传统街区的空间与商业吸引力出现长期变化。 | “经济改革直接导致衰落”是待证因果命题，不应单凭感觉断言。 |
| 1996年以后 | 北京西站开通后分流丰台站的大量运输任务，铁路部门官方史料确认丰台站功能地位下降。 | 运输转移是经证实的结构性变化，但单店客流趋势及影响权重未量化。 |
| 2003年前后 | 应允许 2003 SARS 作为时代切片/全市背景事件。 | 尚无专门证据证明疫情是正阳大街商业形态变迁的主要拐点。 |
| 2010年 | 老丰台站停止办理客运。 | 不得把2010年停客运写成1990年代末车站立即停用。 |
| 2018—2024年 | 新站改造与周边道路拓宽；2024年正阳大街部分路段开放，街道空间持续重组。 | 现代照片不可直接用作1990年代重建的外观依据。 |

**商铺分布**：2012年回忆说铁路在正阳大街南侧，因此大量老店面集中街北侧。不能把店铺名单当作复原位置表；2025年报道提供更具体的摄影／三维重建线索。

## 4. 重要外部复原资源：应先检索，不直接复制

2025-10-17《丰台时报》介绍：荆志敏、王汉臣曾访问200多名老街坊、用六年时间复原20世纪七八十年代正阳大街与老丰台站，包含**748 m重点街段、11条胡同、41家商铺、130余处建筑**；共制作10集纪录片：《百年正阳大街》7集、《百年丰台站》3集，合称《百年丰台镇的老故事》。报道说影片已上线并由丰台区档案馆收藏。

这是当前优先级很高的**视觉和口述线索**；2026-10-19查询到新闻介绍，尚未验证全部十集的稳定播放地址、素材使用授权或原模型获取权。研究可用其交叉核对街面轮廓、门面序列、铺位名称、桥口，**不得直接抓取模型/截图并作为获准公开资产提交**。

另有北京青年报2024年报道，丰台单身公寓东侧仍有两座早期京奉铁路附属建筑（曾供铁路实习员居住）；属**桥南历史建筑考证线索**，其年代和具体形态须独立调查，不自动认为任何一栋就是某人印象里的店铺或桥口平房。

## 5. 进入数字纪念地图的边界

- 这批公共资料首先登记为**桥区历史研究层**，必要时仅以“桥区／正阳大街街段”作为公共方位提示，不把中心城区变成新的一期全镇施工计划。
- 支持从概览 → 一段街／路线 → 具体桥口或旧址 → 按年代切片选择历史叙述与场景；与 [INTERACTION](../INTERACTION.md) 的入口和返回语义一致。
- 地理注册需显式区分旧铁路上跨桥、1990公路跨四环桥、1990铁路框构桥、2020高速铁路拱桥。桥梁**上下关系、南北相对位置、施工年代**必须分别核查。
- **私人叙述仅留在私有档案**。地图便签草案（如果有）不会因为这份研究文件、PR 合并或代码构建而获得发布许可。
- 各个物理地标的几何/有效年代及别名，需在数据模型的 `Place` / `GeometryRevision` / `TimeAssociation` 和 `SourceRecord` 中单独确认；公共本文不提前改写 `places.json`。
