# 丰台镇桥区与正阳大街：地理结论

铁路北侧为正阳大街及老站前街区，南侧为铁路单位与生活区。正阳大街采用“正阳”写法。此处不扩展一期建设范围，也不注册桥体几何。

| 结构 | 空间关系 | 时段与确定程度 |
| --- | --- | --- |
| 旧丰台跨铁路桥 | 南北向道路上跨东西向铁路 | 曾多次改建；具体拆除年未知 |
| 1990年前后公路桥 | 正阳大街跨西四环，位于铁路跨四环结构北侧 | 1988—1990年建设阶段 |
| 1990年前后铁路框构桥 | 铁路在上、西四环道路在下 | 与北侧公路桥分立 |
| 新六线钢箱拱铁路桥 | 跨西四环及相关铁路，位于正阳桥南侧 | 2020年落梁；不用于早期时间层 |

不同物理桥体使用独立身份；同名不能合并结构。几何、有效时期与别名分别管理。旧桥确切形态和拆除年保持未知。

正阳大街为老站北侧商业街。老丰台站1895年始建、2010年停止客运，新北京丰台站2022年开通。后期道路形态不反投到早期场景。仅结论可进入产品；[公开边界](../CONTENT_PIPELINE.md#地理资料的绝对公开边界)适用于本页。
