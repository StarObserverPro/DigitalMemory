# 地理结果的使用与核验

## 地理资料的绝对公开边界

地理查证仅可向本仓库注入可用于产品的结论和必要的确定程度。**绝对禁止提交或披露挖掘、检索、论证、溯源及其过程记录**，包括检索词、查询链接/参数、阅读或访问记录、资料清单、证据链、候选与排除过程、反复调查轨迹、后续追查计划、用户提问动机及个人关联。材料来自公开网站也不能豁免此禁令。

此规则覆盖正文、历史任务包、数据和素材元数据、代码注释、提交信息、分支名、Issue/PR正文与评论、CI日志和制品。不得将过程改名为“公开研究”“证据账本”“冷历史”“交接”继续留存，也不得在删除说明里复述被删内容。仓库任务范围只写工程目标、允许的结果、实现边界和检查状态；地理调查本身无需在仓库建立任务或留痕。

公开结果可写地点、空间关系、有效时期、近似范围以及“已确认／近似／未知”；不得附带如何得出该结果或为何关注该地点。产品许可所必需的第三方署名只保留最小许可信息，不扩展为调查档案。核验在仓库外完成；无法公开过程时仍须保证结论准确，未知保持未知。

旧规范中要求公开地理证据链、来源索引、检索记录、逐次纠错或调查交接的条款全部失效。普通删除提交仍会留下Git历史与旧PR差异；不得据此宣称历史内容已清除。

## 地图地理层的结果要求

本页规定允许公开的地理结果如何进入工程。四层分工见 [ARCHITECTURE](ARCHITECTURE.md#layer-scopes)，源几何与画面表达的具体边界见 [MAP_ASSEMBLY](MAP_ASSEMBLY.md#map-geography-scope)。本层提供稳定身份、空间关系、登记坐标及适用时期；当前时期由时间 resolver 选择，交互行为由 [INTERACTION](INTERACTION.md) 规定。

在仓库外确认地点身份、街段、路侧、朝向、适用时期与所需空间关系。地址和视口中心不足以确定入口；现代形态不能自动代表历史。仅将可支持的结论及确定程度写入产品数据。

- 已确认的身份与位置、近似的进深和退界、未知的边界分别表达。
- 未确定的商号不绑定任意门脸；未知入口不生成传送落点。
- 明确纠正后更新错误身份及依赖它的标注，保留稳定地点ID。
- 源几何、展示几何、时间状态与导航各有所有者。绘制取舍不修改真实空间关系。
- 地理结论与工程验证分开。工程测试证明数据一致性与功能行为，不认证历史真实性。

## 工程接入

输入为已允许公开的空间结果。登记明确坐标基准、单位、轴向、frame 和修订，转换统一经过现有空间/插画映射模块；高度、平面与时期独立表达。绘画和碰撞不得反向改写地理结果；时间缺失保持未知。发布前检查完整 diff、元数据、引用和日志，不包含调查资料。通用工具和必要许可可保留，特定地点的查询实例及运行轨迹不入库。

| 改动 | 同步范围与验收 |
| --- | --- |
| 身份或几何修订 | 保留稳定地点 ID，明确实际变化；核对注册引用、坐标往返、总览命中、街景占地、导航与目的地。检查已有内容锚点，所需重新映射须显式完成。 |
| 入口、路段或通行关系 | 核对路侧、高程和连接层级；街景的可走/可落地规则由导航消费，UI 菜单分组不创造连接。当前新华街直接横穿规则不能被旧的强制过街节点覆盖。 |
| 有效时期或环境状态 | 更新明确的时期成员和确定程度，经既有 resolver 选择；核对所影响的场景、内容及素材，避免最近年份回退或从当代轮廓补出旧貌。 |
| 显示高度、裁剪、轮廓、标签或细节档位 | 归视觉表达修改；证明源占地、高度、年代、登记锚点和碰撞输入未变，再检查实际画面。 |
| 文字或记忆内容 | 交由记忆挂载层更新目标内容；沿用位置和返回上下文，不据此生成新建筑、移动入口或重建整张地图。 |

发生跨层影响时，在同一任务/PR 中列明受影响消费者和规范所有者，只重建依赖该修订的派生结果。共享 frame 或身份变更须覆盖全部引用该记录的消费者；局部构图或内容修改不扩成全图重做。尚未实现的通用挂载迁移必须标为目标契约，不能写成自动完成。

## 当前代码接缝与验收

- `src/domain/spatial.js` 与 `src/domain/illustration.js` 提供注册和坐标对应；绘图分组及标签位置不是新的空间权威。
- `src/domain/temporal.js` 只选择明确接受的时期成员，不用画风、楼高或邻近年份补足历史。
- `scenes/xinhua-sanli-outline/navigation.mjs` 从场景地面及原始建筑占地等记录派生导航；`src/explorer/destinations.js` 为现有锚点分组并解析有效落点，不创建新的地理或记忆记录。
- `src/explorer/outline-stage.js` 连接注册、时间状态、导航和应用 session；资源释放或显示简化不改变这些数据所有权。

验收记录只写工程输入修订、检查对象、实际结果与剩余缺口。至少覆盖本次受影响的坐标对应、源/显示分离、时期选择、导航落点及现有挂载；画面改变另查最终视图。工程检查通过不能替代地理结论的准确性，也不能把美术认可升级为历史确认。
