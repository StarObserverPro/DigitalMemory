# Local visual constraints

Use plain apartment volumes, elongated slabs, compact towers, enclosed balcony bands and independent street-front buildings. Preserve the accepted footprint, orientation, setback and height family. Do not add ornamental courtyard eaves or invented historical occupants.

Contemporary appearance does not establish an earlier state. Abstract legacy modules remain proxies; the current selected overview and outline street are described in [STATUS](STATUS.md). Geographic conclusions are in [the building brief](research/XINHUA_BUILDING_SURVEY.md); investigation material is excluded under [CONTENT_PIPELINE](CONTENT_PIPELINE.md#地理资料的绝对公开边界).
