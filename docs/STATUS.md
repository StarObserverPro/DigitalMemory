| Surface | Implemented | Not implied |

The foundation's scope, exact tests and handoff are recorded in [DM-PRIVATE-CONTENT-MOUNT](attention/tasks/DM-PRIVATE-CONTENT-MOUNT.md). Local synthetic tests, CI, review, main merge and production activation are separate states. In particular the Drive draft cannot be consumed by the approved-release reader, and connected ChatGPT Drive access is not website authorization.

## Before production private reading

A real session provider with revocation/rate limits, dedicated readonly Drive identity, same-origin server route, private street reader/return/cleanup integration, authorized live read, cross-tab/back-forward-cache logout and restore/withdrawal verification are still required. See [PRIVATE_CONTENT_RUNBOOK](PRIVATE_CONTENT_RUNBOOK.md). Until those gates pass, the public application remains usable with the private layer absent.
