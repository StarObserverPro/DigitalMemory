# Fourth Ring bridge extension

Selected native geometry and ink for the roughly 2000–2005 Fourth Ring working composite. Includes the Kefeng bend, Kandan, separate Fengtai road/rail bridges, Beidadi and a simple Fengbei end. Dimensions and side profiles are approximate. The newer Fengtai railway steel arch is excluded.

The selected outline data owns coordinates/profiles. `content/public/outline-registration.json` pins the model frame and period membership. The existing street supplies the renderer, camera, session, navigation input, transition and disposal; this package creates no independent application.

Closed undersides, top-facing ground, finite retaining walls and non-depth-writing appearance overlays have separate depth roles. Base paper is absent across the depressed passage. All 16 simplified lamps have three fixed solid rounded ray strokes; no internal detail or glare compositor. Continuous fixed world paths distinguish the road and sidewalk. The same surface heights and supports feed navigation and camera collision.

Only selected runtime modules enter this package. Review UI, diagnostics, screenshots, original pictures and trial variants are excluded. OpenStreetMap attribution remains in the selected data. Representation acceptance does not certify exact historical dimensions.
