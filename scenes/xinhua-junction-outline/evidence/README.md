# 版本与验证边界

| 记录 | 对应版本 | 用途 |
| --- | --- | --- |
| http-verification.json | outline-street-r4-02 | 冻结的空间与导航哈希比较基线 |
| http-ink-verification.json | outline-motion-r4-04 | 上次轮廓让线与动态修订的资源检查 |
| browser-ink-verification.json | outline-motion-r4-04 | 上次实际浏览器步行、近建筑、远树、店声与停止检查；其中截图名称指库外旧 QA，不是本库资源 |
| http-library-verification.json | outline-motion-r4-05 | 本次入库运行字节、空间不变与资料隔离检查 |
| library-verification.json | outline-motion-r4-05 | 本次自动检查与实际浏览器观察，包含删电线后的 consumer 记录 |

用户认可的是 r4-04 路口可入库，并指示删除电线。r4-05 执行这个局部纠正；原始多点位图像和试画不入库。本目录不保存截图、PID、服务日志或私人源材料。渲染检查不等于所有视角/设备均被穷尽，也不构成历史真实性认证。
