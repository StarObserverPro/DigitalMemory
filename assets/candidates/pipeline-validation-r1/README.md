Three compounds × three final display tiers in one native atlas. Built-in image_gen; exact prompts in prompts.json. No production assets replaced.

Attempt 1: seven size passes, two returns; unwanted fine facade grids. Attempt 2: nine size passes, native subject/display dimensions approximately 1.11–1.24 per axis; larger crop margins and simpler marks. All generated outputs remain candidates.

Ground probes in assembly-review.webp expose internal correspondence drift despite size acceptance. Do not promote these whole-compound images to registered production assets; split component groups or correct geometry/re-render. No nonuniform warp is used in the fixture. The road in that fixture is a schematic occlusion test. Review is native image evidence, not a browser screenshot.
