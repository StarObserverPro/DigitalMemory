# 新华街小区试贴 r3

本版依用户 2026-10-18 校正，将南侧六里改为老式红砖步梯板楼，北侧七里/五里西区外围板楼改成较高、较现代的公寓体量。约十层以上是本次造型参考，不是逐栋确认。r2 中五里西区低板楼来源仍保留：其“六层”条目与这次回忆的适用对象可能不同，不能直接当作同一栋楼的矛盾已经解决。

三个 SVG 为中间构图稿，*-guide.png 实际传入内置 image_gen；prompts.json 为完整提示词。三个 *-illustrated.webp 为透明成图，现已用于大地图试贴。未改道路、未把店铺画进住宅、无新地图人物或常驻控制。

正式位置数据集中在 content/public/overview-registration.json 的 trialCompounds。原图中的楼脚候选点与参考平面位置配对，以最小二乘拟合后记录三角控制框；运行时仍由唯一地理变换生成 SVG 矩阵。七里/五里西区参考 OSM 轮廓，六里仍是有屋顶位移不确定性的人工描摹。参考像素残差约 3–9px RMS，代表拟合误差，不代表测量精度或历史真实性。矢量道路始终独立绘制，道路走廊遮罩保护通行空间。

远景稍淡；中、近景保持同一落点和相同图像，仅改变显示尺度与标注预算。本版不是三个独立精度的全新画稿。院子纹理已经成图，后续增加独立楼/店铺应修改对应构图或以局部覆盖资产替换，不能称整张图片已具备逐楼编辑能力。

素材色彩、比例按本轮试贴授权使用，未声称最终审美通过。未逐栋核对楼号、楼层、精确院界或所选年代；现代影像拍摄日期未知。源卫星图不分发。沿用 r2/source.json 的 Esri 参考元数据与 OSM contributors / ODbL 署名。
