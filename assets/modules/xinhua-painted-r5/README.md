# Xinhua painted overview R5

R6 retires the eleven compound images and detached frontage. Only the surrounding road/ground painting and three unchanged landmark cutouts remain in use. The old provenance is retained as historical metadata; its compound layouts were geographically rejected. Current Xinhua art and registration are in `xinhua-wax-r6`.

Original built-in imagegen paintings use warm pen, selective directional hatching and light watercolor. Exports use mechanical cropping and WebP encoding with transparency. Registration applies uniform scale/translation only. Invisible masks separate painted ground, raised buildings and a cropped shop; SVG contributes no visible map artwork.

`provenance.json` records source-frame hashes/crops and public reference roles. Raw generations, rejected outputs, guides, source satellite images, example boards and QA pictures are excluded from this directory and outgoing history. Public geography and partial 2011 imagery inform an approximate earlier composite; generated details are not historical evidence. User aesthetic approval is pending.
